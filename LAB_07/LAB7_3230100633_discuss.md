我想量化 Project 1 中不同 P 值下边缘的平滑程度。量化方法是对边缘做 Fourier Transform，高频分量越多，边缘越不平滑。

最初使用“高频能量占比”的硬阈值方法，但发现很多 P 值下平滑度都接近 1，区分度不明显。原因是重建轮廓本身只保留了低频描述子，如果高频阈值设得过高，阈值以上能量为 0，就会导致多个 P 的结果没有差异。

后来改为频率加权的高频能量：

```text
WeightedHighFreqEnergy = sum(normalized_frequency * FourierEnergy) / total_energy
Smoothness = 1 - WeightedHighFreqEnergy
```

为了让结果更适合报告展示，又增加了 `ScaledSmoothness`，将当前 P 值范围内的平滑程度映射到 `[0.5, 1.0]`。结果显示：P 较小时边界更平滑，P 增大后恢复更多高频细节，平滑程度下降，形状精度提高。

import h5py
import numpy as np
import matplotlib.pyplot as plt
import os

def read_and_show_mat_images(data_dir='data', num_samples=4):
    """
    读取 .mat 文件中的图像数据并显示
    
    Parameters:
    -----------
    data_dir : str
        数据文件夹路径
    num_samples : int
        显示的样本数量
    """
    # 获取所有 .mat 文件
    mat_files = [f for f in os.listdir(data_dir) if f.endswith('.mat')]
    mat_files.sort(key=lambda x: int(x.split('.')[0]))  # 按数字排序
    
    print(f"找到 {len(mat_files)} 个 .mat 文件")
    
    fig, axes = plt.subplots(1, min(num_samples, len(mat_files)), 
                             figsize=(15, 5))
    if num_samples == 1:
        axes = [axes]
    
    for idx, mat_file in enumerate(mat_files[:num_samples]):
        filepath = os.path.join(data_dir, mat_file)
        
        try:
            with h5py.File(filepath, 'r') as f:
                print(f"\n读取: {mat_file}")
                print(f"数据集: {list(f.keys())}")
                
                # 尝试常见的变量名
                # 根据你的数据调整变量名，常见的有：'data', 'image', 'img', 'X' 等

                image_data = None
                actual_name = None
                
                for name in possible_names:
                    if name in f:
                        image_data = f[name][:]
                        actual_name = name
                        break
                
                # 如果上述名称都不存在，使用第一个数据集
                if image_data is None and len(f.keys()) > 0:
                    first_key = list(f.keys())[0]
                    image_data = f[first_key][:]
                    actual_name = first_key
                
                if image_data is not None:
                    print(f"使用变量: {actual_name}")
                    print(f"数据形状: {image_data.shape}")
                    print(f"数据类型: {image_data.dtype}")
                    print(f"数值范围: [{image_data.min():.4f}, {image_data.max():.4f}]")
                    
                    # 处理数据维度
                    # MATLAB 存储是列优先，可能需要转置
                    if len(image_data.shape) == 4:  # 批处理图像 [N, H, W, C] 或 [C, H, W, N]

                    elif len(image_data.shape) == 3:
                        if image_data.shape[0] == 3 or image_data.shape[0] == 1:  
                            # 通道在前 [C, H, W]

                            # 通道在后 [H, W, C]
                            img = image_data
                    elif len(image_data.shape) == 2:  # 灰度图
                        img = image_data
                    else:
                        print(f"意外的数据维度: {image_data.shape}")
                        continue
                    
                    # 归一化到 [0, 1] 用于显示

                        img = img / 255.0 if img.max() <= 255.0 else img / img.max()
                    
                    # 显示图像

                    axes[idx].set_title(f'{mat_file}\n{actual_name}: {image_data.shape}')
                    axes[idx].axis('off')
                    
        except Exception as e:
            print(f"读取 {mat_file} 时出错: {e}")
    
    plt.tight_layout()
    plt.show()

Implement the Fourier Descriptors extraction 数学上的流程是怎么样的？


Fourier Descriptors（傅里叶描述子）是一种强大的形状描述方法，通过将轮廓坐标转换到频域来提取形状特征。以下是完整的数学流程：

## 1. 数学基础原理

### 核心思想
将二维轮廓表示为一维复数序列，然后通过傅里叶变换将其分解为不同频率的谐波分量。

## 2. 完整数学流程

### Step 1: 轮廓提取与表示

给定一个闭合轮廓，由 N 个点组成：
$$(x_k, y_k), \quad k = 0, 1, ..., N-1$$

将每个点表示为复数：
$$s(k) = x(k) + j \cdot y(k), \quad j = \sqrt{-1}$$

这形成了一个一维复数序列。

### Step 2: 离散傅里叶变换 (DFT)

对复数序列 $s(k)$ 进行 DFT：

$$a(u) = \sum_{k=0}^{N-1} s(k) \cdot e^{-j2\pi uk/N}, \quad u = 0, 1, ..., N-1$$

其中：
- $a(u)$ 是傅里叶系数（复数）
- $u$ 是频率索引
- $N$ 是轮廓点总数

### Step 3: 傅里叶描述子的性质

傅里叶系数具有以下重要性质：

**低频分量** $(u \approx 0)$ 表示形状的整体轮廓  
**高频分量** $(u \approx N/2)$ 表示细节特征

**几何变换的对应关系：**

| 几何变换 | 傅里叶描述子的变化 |
|---------|------------------|
| 平移 | 仅影响 $a(0)$ |
| 旋转 | 所有系数乘 $e^{j\theta}$ |
| 缩放 | 所有系数乘常数因子 |
| 起始点变化 | 系数乘 $e^{-j2\pi uk_0/N}$ |

### Step 4: 归一化（使描述子具有不变性）

为了实现**平移、旋转、缩放不变性**，需要进行归一化：

**平移不变性：**
$$a(0) = 0 \quad \text{或忽略} \quad a(0)$$

**缩放不变性：**
$$\tilde{a}(u) = \frac{a(u)}{|a(1)|} \quad \text{（除以第一个非零系数的模）}$$

**旋转和起始点不变性（只保留幅度）：**
$$d(u) = \frac{|a(u)|}{|a(1)|}, \quad u = 1, 2, ..., N-1$$

或保持相位信息（用于重建）：
$$\tilde{a}(u) = \frac{a(u) \cdot a(1)^*}{|a(1)|^2}$$

### Step 5: 选择描述子数量

通常只保留前 M 个低频系数：
$$FD = [d(1), d(2), ..., d(M)]$$

其中 $M \ll N$，常用 $M = 10 \sim 30$。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial import distance
import cv2

def extract_contour_complex(image, method='largest'):
    """
    从图像提取轮廓并转换为复数序列
    
    Parameters:
    -----------
    image : ndarray
        二值图像或灰度图像
    method : str
        'largest': 最大轮廓, 'all': 所有轮廓
    
    Returns:
    --------
    contours_complex : list
        复数形式的轮廓序列
    """
    # 如果是灰度图，先二值化
    if len(image.shape) == 3:
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    else:
        gray = image.copy()
    
    if gray.max() > 1:
        _, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
    else:
        _, binary = cv2.threshold(gray, 0.5, 1, cv2.THRESH_BINARY)
    
    binary = binary.astype(np.uint8)
    
    # 提取轮廓
    contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, 
                                   cv2.CHAIN_APPROX_NONE)
    
    if len(contours) == 0:
        return None
    
    if method == 'largest':
        contour = max(contours, key=cv2.contourArea)
        contours = [contour]
    
    # 转换为复数序列
    contours_complex = []
    for contour in contours:
        contour = contour.squeeze()
        if contour.ndim == 1:
            contour = contour.reshape(-1, 2)
        
        # 确保闭合
        if not np.array_equal(contour[0], contour[-1]):
            contour = np.vstack([contour, contour[0]])
        
        # 转换为复数: s(k) = x(k) + j*y(k)
        s = contour[:, 0] + 1j * contour[:, 1]
        contours_complex.append(s)
    
    return contours_complex

def compute_fourier_descriptors(contour_complex, num_descriptors=None):
    """
    计算傅里叶描述子
    
    Parameters:
    -----------
    contour_complex : ndarray
        复数形式的轮廓序列 s(k) = x(k) + j*y(k)
    num_descriptors : int
        保留的描述子数量
    
    Returns:
    --------
    descriptors : ndarray
        傅里叶描述子（归一化后的幅度）
    fourier_coeffs : ndarray
        原始傅里叶系数
    """
    N = len(contour_complex)
    
    # Step 2: DFT
    # a(u) = sum(s(k) * exp(-j*2*pi*u*k/N))
    fourier_coeffs = np.fft.fft(contour_complex)
    
    # Step 4: 归一化
    # 平移不变性：忽略 a(0)
    # 缩放不变性：除以 |a(1)|
    # 旋转不变性：取幅度
    if N > 1:
        scale = np.abs(fourier_coeffs[1])
        if scale > 0:
            descriptors = np.abs(fourier_coeffs) / scale
        else:
            descriptors = np.abs(fourier_coeffs)
    else:
        descriptors = np.abs(fourier_coeffs)
    
    # Step 5: 截取前 M 个描述子
    if num_descriptors is not None:
        # 保留前 M 个非零频率分量
        descriptors = descriptors[1:min(num_descriptors+1, N)]  # 跳过 DC 分量
    else:
        descriptors = descriptors[1:]  # 跳过 DC 分量
    
    return descriptors, fourier_coeffs

def reconstruct_contour(fourier_coeffs, num_coeffs=None):
    """
    从傅里叶系数重建轮廓
    
    Parameters:
    -----------
    fourier_coeffs : ndarray
        傅里叶系数
    num_coeffs : int
        用于重建的系数数量（低通滤波）
    
    Returns:
    --------
    reconstructed : ndarray
        重建的轮廓点
    """
    if num_coeffs is not None:
        # 创建滤波后的系数
        filtered = np.zeros_like(fourier_coeffs)
        N = len(fourier_coeffs)
        
        # 保留低频分量（对称）
        half = num_coeffs // 2
        filtered[0:half+1] = fourier_coeffs[0:half+1]
        if half > 0:
            filtered[-half:] = fourier_coeffs[-half:]
    else:
        filtered = fourier_coeffs
    
    # 逆傅里叶变换
    reconstructed = np.fft.ifft(filtered)
    
    return np.real(reconstructed), np.imag(reconstructed)

def elliptical_fourier_descriptors(contour, order=10):
    """
    椭圆傅里叶描述子（Elliptic Fourier Descriptors）
    独立处理 x 和 y 坐标
    
    Parameters:
    -----------
    contour : ndarray
        轮廓点 N×2
    order : int
        谐波阶数
    
    Returns:
    --------
    descriptors : ndarray
        椭圆傅里叶描述子
    """
    # 闭合轮廓
    if not np.array_equal(contour[0], contour[-1]):
        contour = np.vstack([contour, contour[0]])
    
    x = contour[:, 0]
    y = contour[:, 1]
    N = len(contour)
    T = N  # 周期
    
    # 计算差分
    dx = np.diff(x)
    dy = np.diff(y)
    dt = np.sqrt(dx**2 + dy**2)
    t = np.cumsum(dt)
    t = np.insert(t, 0, 0)
    
    # 计算系数
    T = t[-1]
    descriptors = []
    
    for n in range(1, order + 1):
        # 傅里叶系数计算
        an = (T / (2 * np.pi**2 * n**2)) * np.sum(
            (dx / dt[1:]) * (np.cos(2*np.pi*n*t[1:]/T) - 
                           np.cos(2*np.pi*n*t[:-1]/T))
        )
        bn = (T / (2 * np.pi**2 * n**2)) * np.sum(
            (dx / dt[1:]) * (np.sin(2*np.pi*n*t[1:]/T) - 
                           np.sin(2*np.pi*n*t[:-1]/T))
        )
        cn = (T / (2 * np.pi**2 * n**2)) * np.sum(
            (dy / dt[1:]) * (np.cos(2*np.pi*n*t[1:]/T) - 
                           np.cos(2*np.pi*n*t[:-1]/T))
        )
        dn = (T / (2 * np.pi**2 * n**2)) * np.sum(
            (dy / dt[1:]) * (np.sin(2*np.pi*n*t[1:]/T) - 
                           np.sin(2*np.pi*n*t[:-1]/T))
        )
        
        descriptors.append([an, bn, cn, dn])
    
    return np.array(descriptors)

def shape_matching(descriptors1, descriptors2, metric='euclidean'):
    """
    形状匹配：比较两个傅里叶描述子
    
    Parameters:
    -----------
    descriptors1, descriptors2 : ndarray
        傅里叶描述子
    metric : str
        距离度量方法
    
    Returns:
    --------
    distance : float
        形状相似度（越小越相似）
    """
    # 确保长度一致
    min_len = min(len(descriptors1), len(descriptors2))
    d1 = descriptors1[:min_len]
    d2 = descriptors2[:min_len]
    
    if metric == 'euclidean':
        distance = np.sqrt(np.sum((d1 - d2)**2))
    elif metric == 'manhattan':
        distance = np.sum(np.abs(d1 - d2))
    elif metric == 'cosine':
        distance = 1 - np.dot(d1, d2) / (np.linalg.norm(d1) * np.linalg.norm(d2))
    else:
        distance = np.sqrt(np.sum((d1 - d2)**2))
    
    return distance
```

## 4. 关键数学公式总结

### 离散傅里叶变换（DFT）：
$$F(u) = \sum_{k=0}^{N-1} f(k) \cdot e^{-j2\pi uk/N}$$

### 逆变换（IDFT）：
$$f(k) = \frac{1}{N} \sum_{u=0}^{N-1} F(u) \cdot e^{j2\pi uk/N}$$

### 归一化傅里叶描述子：
$$FD(u) = \frac{|F(u)|}{|F(1)|}, \quad u = 1, 2, ..., M$$

### 形状相似度（欧氏距离）：
$$d = \sqrt{\sum_{i=1}^{M} (FD_1(i) - FD_2(i))^2}$$

这里的量化真实病灶区域是在干什么？


这里的**"量化真实病灶区域"（Quantized Real Tumor ROI）**是进行**纹理分析的关键预处理步骤**，其目的是**降低图像灰度级数**，使得后续的灰度共生矩阵（GLCM）计算变得可行且高效。

让我详细解释这个过程的数学原理和实际意义：

## 1. 为什么需要量化？

### 原始图像的问题：
- 医学图像通常是 **12-16 bit** 的深度（4096-65536个灰度级）
- CT/MRI 图像的 HU 值范围可能从 -1000 到 +3000
- 如果直接计算 GLCM，矩阵大小将是 `65536 × 65536`，这在实际中**不可行**

### 量化的作用：
将灰度级从原来的 `2^B` 级**重新映射**到 `N_g` 个离散级别：

$$I_{quantized}(x,y) = \left\lfloor \frac{I(x,y) - I_{min}}{I_{max} - I_{min}} \times (N_g - 1) \right\rfloor + 1$$

其中：
- $I(x,y)$ 是原始图像灰度值
- $N_g$ 是量化后的灰度级数（通常为 8, 16, 32, 64, 128, 256）
- $I_{quantized}$ 的范围是 $[1, N_g]$

## 2. 量化的数学意义

### 信息压缩与保留：
$$\text{Quantization Function: } Q(I) = \text{round}\left(\frac{I - I_{min}}{I_{max} - I_{min}} \times (N_g - 1)\right)$$

这个操作：
1. **降低计算复杂度**：GLCM 大小从 $(2^{12})^2$ 降到 $(2^6)^2$ 或 $(2^8)^2$
2. **保持纹理信息**：合理选择 $N_g$ 可以保留足够的纹理特征
3. **标准化**：不同扫描的量化结果可比较

```python
import numpy as np
import matplotlib.pyplot as plt
from skimage.feature import graycomatrix, graycoprops
from scipy import stats
import cv2

class TumorTextureAnalyzer:
    """肿瘤纹理分析器 - 包含量化和GLCM计算"""
    
    def __init__(self, n_levels=64):
        """
        初始化分析器
        
        Parameters:
        -----------
        n_levels : int
            量化级别（灰度级数）
        """
        self.n_levels = n_levels
    
    def quantize_tumor_roi(self, roi_image, n_levels=None):
        """
        量化肿瘤ROI图像
        
        Parameters:
        -----------
        roi_image : ndarray
            原始肿瘤ROI图像（可能有多种灰度级）
        n_levels : int, optional
            量化级数，默认使用初始化值
        
        Returns:
        --------
        quantized : ndarray
            量化后的图像
        original_min, original_max : tuple
            原始范围，用于后续解释
        """
        if n_levels is None:
            n_levels = self.n_levels
        
        # 只考虑肿瘤区域（非零像素）
        tumor_mask = roi_image > 0
        tumor_pixels = roi_image[tumor_mask]
        
        if len(tumor_pixels) == 0:
            raise ValueError("No tumor pixels found in ROI")
        
        # 计算肿瘤区域的灰度范围
        original_min = tumor_pixels.min()
        original_max = tumor_pixels.max()
        original_range = original_max - original_min
        
        print(f"原始肿瘤灰度范围: [{original_min:.1f}, {original_max:.1f}]")
        print(f"动态范围: {original_range:.1f}")
        
        # 执行量化
        quantized = np.zeros_like(roi_image, dtype=np.uint8)
        
        if original_range > 0:
            # 线性量化映射
            normalized = (roi_image - original_min) / original_range
            quantized[tumor_mask] = np.clip(
                np.round(normalized[tumor_mask] * (n_levels - 1)) + 1,
                1, n_levels
            ).astype(np.uint8)
        else:
            # 如果所有值相同，全部量化为1
            quantized[tumor_mask] = 1
        
        return quantized, original_min, original_max
    
    def compute_glcm_with_relationships(self, quantized_image, 
                                       distances=[1, 2, 3],
                                       angles=[0, np.pi/4, np.pi/2, 3*np.pi/4]):
        """
        计算基于特定空间关系的GLCM
        
        Parameters:
        -----------
        quantized_image : ndarray
            量化后的图像
        distances : list
            像素距离
        angles : list
            方向角度（弧度）
        
        Returns:
        --------
        glcm : ndarray
            4D GLCM矩阵 (n_levels, n_levels, distances, angles)
        glcm_properties : dict
            GLCM统计属性
        """
        # 确保量化级数一致
        n_levels = self.n_levels
        
        # 计算GLCM
        glcm = graycomatrix(
            quantized_image,
            distances=distances,
            angles=angles,
            levels=n_levels,
            symmetric=True,  # 对称GLCM
            normed=True       # 归一化为概率
        )
        
        # 计算GLCM属性
        properties = ['contrast', 'dissimilarity', 'homogeneity', 
                     'energy', 'correlation', 'ASM']
        
        glcm_properties = {}
        for prop in properties:
            values = graycoprops(glcm, prop)
            glcm_properties[prop] = values
        
        return glcm, glcm_properties
    
    def compute_second_order_statistics(self, quantized_image):
        """
        计算二阶统计量（基于GLCM）
        
        Parameters:
        -----------
        quantized_image : ndarray
            量化后的图像
        
        Returns:
        --------
        stats_dict : dict
            二阶统计量字典
        """
        tumor_mask = quantized_image > 0
        
        # 获取肿瘤区域的量化值
        tumor_values = quantized_image[tumor_mask]
        
        # 计算多距离、多角度的GLCM
        distances = [1, 2, 4, 8]  # 不同尺度
        angles = [0, np.pi/4, np.pi/2, 3*np.pi/4]  # 四个方向
        
        glcm, glcm_props = self.compute_glcm_with_relationships(
            quantized_image, distances, angles
        )
        
        # 汇总统计量
        stats_dict = {
            'tumor_size': len(tumor_values),
            'quantized_range': [tumor_values.min(), tumor_values.max()],
            'n_levels': self.n_levels,
            'distances': distances,
            'angles': angles
        }
        
        # 对每个属性，计算跨距离和角度的平均值和标准差
        for prop_name, prop_values in glcm_props.items():
            stats_dict[f'{prop_name}_mean'] = np.mean(prop_values)
            stats_dict[f'{prop_name}_std'] = np.std(prop_values)
            
            # 每个距离的平均值
            for i, dist in enumerate(distances):
                stats_dict[f'{prop_name}_d{dist}'] = np.mean(prop_values[i, :])
        
        return stats_dict, glcm, glcm_props
    
    def analyze_tumor_texture(self, roi_image, visualize=True):
        """
        完整的肿瘤纹理分析流程
        
        Parameters:
        -----------
        roi_image : ndarray
            肿瘤ROI图像
        visualize : bool
            是否可视化
            
        Returns:
        --------
        results : dict
            包含所有分析结果的字典
        """
        results = {}
        
        # Step 1: 量化
        print("=" * 50)
        print("Step 1: 量化肿瘤ROI")
        print("=" * 50)
        quantized, orig_min, orig_max = self.quantize_tumor_roi(roi_image)
        results['quantized_image'] = quantized
        results['original_range'] = (orig_min, orig_max)
        
        # Step 2: 一阶统计量（基线）
        print("\n" + "=" * 50)
        print("Step 2: 一阶统计量（灰度直方图特征）")
        print("=" * 50)
        tumor_pixels = roi_image[roi_image > 0]
```

## 4. 量化的临床意义

### 为什么在肿瘤分析中重要：

1. **纹理异质性评估**：
   - 恶性肿瘤通常表现出更异质的纹理
   - 量化后的GLCM可以捕捉这种异质性

2. **治疗反应监测**：
   - 治疗前后纹理变化
   - 量化确保了可比性

3. **预后预测**：
   - 特定的纹理模式与预后相关
   - 标准化处理使不同患者的数据可比较

4. **计算可行性**：
   - 原始CT值范围[-1000, 3000] → 量化到64级
   - GLCM从4000²降到64²，计算量减少约3900倍

## 5. 关键概念总结

| 概念 | 说明 | 数学表达 |
|------|------|----------|
| **量化** | 减少灰度级数 | $Q(I) = \lfloor\frac{I-I_{min}}{I_{max}-I_{min}} \times (N_g-1)\rfloor$ |
| **GLCM** | 像素对的联合概率 | $P(i,j|d,\theta)$ |
| **空间关系** | 距离d和角度θ | $(d,\theta) \in \{(1,0°), (1,45°), (1,90°), (1,135°), ...\}$ |
| **二阶统计** | 像素对的关系 | Contrast, Homogeneity, Energy, Correlation, etc. |

**量化是连接原始医学图像和高阶纹理分析的桥梁，使得纹理特征的提取在计算上可行，在统计上有意义。**

GLCM 的采样步长如何与周期性结构纹理相互作用，想要探究这个之间的关系，流程是怎么样的？


探究**GLCM采样步长与周期性结构纹理的相互作用**是一个系统性实验，下面是完整的研究流程：

## 完整研究流程

```python
import numpy as np
import matplotlib.pyplot as plt
from skimage.feature import graycomatrix, graycoprops
from scipy import signal, stats, ndimage
from scipy.fft import fft2, fftshift
import seaborn as sns
from mpl_toolkits.axes_grid1 import make_axes_locatable
import warnings
warnings.filterwarnings('ignore')

# 设置中文字体（如需要）
plt.rcParams['font.size'] = 10
plt.rcParams['figure.dpi'] = 100

class StepSizeTextureAnalysis:
    """
    GLCM步长与周期纹理交互作用研究系统
    """
    
    def __init__(self, n_levels=64):
        self.n_levels = n_levels
    
    # ================================================================
    # 阶段1: 生成可控的周期性纹理
    # ================================================================
    def generate_periodic_textures(self, size=256):
        """
        生成不同类型的周期性纹理
        
        控制变量：
        - 周期T
        - 纹理类型（正弦、方波、棋盘等）
        - 方向性
        """
        textures = {}
        
        # 1. 水平正弦纹理 - 不同周期
        x = np.arange(size)
        for period in [4, 8, 16, 32, 64]:
            texture = 128 + 127 * np.sin(2 * np.pi * x / period)
            textures[f'sine_h_T{period}'] = np.tile(texture, (size, 1))
        
        # 2. 垂直方波纹理
        for period in [8, 16, 32]:
            y = np.arange(size)
            texture = np.where(np.sin(2 * np.pi * y / period) > 0, 200, 50)
            textures[f'square_v_T{period}'] = np.tile(texture.reshape(-1, 1), (1, size))
        
        # 3. 棋盘格纹理
        x, y = np.meshgrid(np.arange(size), np.arange(size))
        for period in [8, 16, 32]:
            checker = np.where((x//(period//2) + y//(period//2)) % 2 == 0, 200, 50)
            textures[f'checker_T{period}'] = checker
        
        # 4. 对角条纹纹理
        for period in [16, 32]:
            diagonal = 128 + 127 * np.sin(2 * np.pi * (x + y) / (period * np.sqrt(2)))
            textures[f'diagonal_T{period}'] = diagonal
        
        # 5. 同心圆纹理（径向周期）
        x0, y0 = size//2, size//2
        r = np.sqrt((x - x0)**2 + (y - y0)**2)
        for period in [8, 16, 32]:
            concentric = 128 + 127 * np.sin(2 * np.pi * r / period)
            textures[f'concentric_T{period}'] = concentric
        
        # 6. 复合纹理（多周期叠加）
        texture_multi = np.zeros((size, size))
        for period, weight in [(8, 1.0), (16, 0.5), (32, 0.25)]:
            texture_multi += weight * np.sin(2 * np.pi * x / period)
        texture_multi = 128 + 127 * texture_multi / texture_multi.max()
        textures['multi_period'] = texture_multi
        
        return textures
    
    # ================================================================
    # 阶段2: 系统扫描步长空间
    # ================================================================
    def scan_step_size_space(self, texture, max_step=128, step_increment=1,
                            angles=[0, np.pi/4, np.pi/2, 3*np.pi/4]):
        """
        系统扫描不同的采样步长
        
        对于每个步长d，计算：
        - GLCM矩阵
        - 所有纹理特征
        - 自相关值
        """
        # 量化纹理
        texture_quant = self._quantize(texture)
        
        # 步长序列
        distances = np.arange(1, max_step + 1, step_increment)
        
        # 存储结果
        results = {
            'distances': distances,
            'angles': angles,
            'features': {
                'contrast': np.zeros((len(distances), len(angles))),
                'dissimilarity': np.zeros((len(distances), len(angles))),
                'homogeneity': np.zeros((len(distances), len(angles))),
                'energy': np.zeros((len(distances), len(angles))),
                'correlation': np.zeros((len(distances), len(angles))),
                'ASM': np.zeros((len(distances), len(angles)))
            },
            'glcm_matrices': [],
            'autocorrelation': np.zeros(len(distances))
        }
        
        # 计算自相关函数
        texture_norm = (texture - texture.mean()) / texture.std()
        autocorr_full = signal.correlate2d(texture_norm, texture_norm, mode='same')
        
        for i, d in enumerate(distances):
            # GLCM计算
            glcm = graycomatrix(
                texture_quant,
                distances=[d],
                angles=angles,
                levels=self.n_levels,
                symmetric=True,
                normed=True
            )
            
            # 存储关键GLCM矩阵 (仅水平方向)
            if d in [1, 2, 4, 8, 16, 32, 64, 128]:
                results['glcm_matrices'].append({
                    'distance': d,
                    'matrix': glcm[:, :, 0, 0]  # θ=0
                })
            
            # 提取特征
            for feature_name in results['features'].keys():
                results['features'][feature_name][i, :] = graycoprops(glcm, feature_name)[0, :]
            
            # 提取自相关值 (沿水平方向)
            center = autocorr_full.shape[1] // 2
            if center + d < autocorr_full.shape[1]:
                results['autocorrelation'][i] = np.mean([
                    autocorr_full[center, center + d],
                    autocorr_full[center, center - d]
                ])
        
        return results
    
    # ================================================================
    # 阶段3: 检测共振点
    # ================================================================
    def detect_resonance_points(self, distances, feature_curve, period):
        """
        检测步长与周期的共振点
        
        共振条件：
        - d = n*T (n=1,2,3,...): 同相位对齐 → 高相关性
        - d = (2n+1)*T/2: 反相位对齐 → 高对比度
        """
        resonance_points = {
            'in_phase': [],      # d = n*T
            'anti_phase': [],    # d = (2n+1)*T/2
            'quarter_phase': []  # d = (2n+1)*T/4
        }
        
        max_d = distances[-1]
        
        # 同相位点
        n = 1
        while n * period <= max_d:
            idx = np.argmin(np.abs(distances - n * period))
            resonance_points['in_phase'].append({
                'd': distances[idx],
                'n': n,
                'feature_value': feature_curve[idx]
            })
            n += 1
        
        # 反相位点
        n = 0
        while (2*n + 1) * period / 2 <= max_d:
            d_val = (2*n + 1) * period / 2
            idx = np.argmin(np.abs(distances - d_val))
            resonance_points['anti_phase'].append({
                'd': distances[idx],
                'n': n,
                'feature_value': feature_curve[idx]
            })
            n += 1
        
        return resonance_points
    
    # ================================================================
    # 阶段4: 频谱分析（FFT）
    # ================================================================
    def spectral_analysis(self, texture):
        """
        对纹理进行频谱分析
        
        目的：从频域识别纹理的周期成分
        """
        # 2D FFT
        f_transform = fft2(texture)
        f_shifted = fftshift(f_transform)
        magnitude_spectrum = np.log(np.abs(f_shifted) + 1)
        
        # 提取径向功率谱
        rows, cols = texture.shape
        center_row, center_col = rows // 2, cols // 2
        
        # 主频率检测
        # 沿水平方向
        horizontal_profile = magnitude_spectrum[center_row, center_col:]
        # 沿垂直方向
        vertical_profile = magnitude_spectrum[center_row:, center_col]
        
        # 寻找峰值（主要周期成分）
        from scipy.signal import find_peaks
        
        peaks_h, properties_h = find_peaks(horizontal_profile, 
                                           height=np.mean(horizontal_profile),
                                           distance=2)
        peaks_v, properties_v = find_peaks(vertical_profile,
                                           height=np.mean(vertical_profile),
                                           distance=2)
        
        # 转换频率到周期
        periods_h = []
        for peak in peaks_h:
            if peak > 0:
                frequency = peak / cols
                if frequency > 0:
                    periods_h.append(1 / frequency)
        
        periods_v = []
        for peak in peaks_v:
            if peak > 0:
                frequency = peak / rows
                if frequency > 0:
                    periods_v.append(1 / frequency)
        
        return {
            'magnitude_spectrum': magnitude_spectrum,
            'horizontal_profile': horizontal_profile,
            'vertical_profile': vertical_profile,
            'peaks_horizontal': peaks_h,
            'peaks_vertical': peaks_v,
            'periods_horizontal': periods_h,
            'periods_vertical': periods_v,
            'f_transform': f_shifted
        }
    
    # ================================================================
    # 阶段5: 完整的交互作用分析
    # ================================================================
    def analyze_interaction(self, texture, known_period=None, max_step=None):
        """
        完整分析步长与周期纹理的交互作用
        
        Parameters:
        -----------
        texture : ndarray
            输入纹理图像
        known_period : int or None
            已知周期（如果有的话）
        max_step : int or None
            最大步长，None则自动设为图像尺寸的1/4
        """
        if max_step is None:
            max_step = min(texture.shape) // 4
        
        print("=" * 60)
        print("GLCM步长与周期纹理交互作用分析")
        print("=" * 60)
        
        # Step 1: 频谱分析获取周期信息
        print("\n[1/5] 频谱分析...")
        spectral_info = self.spectral_analysis(texture)
        
        if known_period is None and len(spectral_info['periods_horizontal']) > 0:
            detected_period = int(np.round(spectral_info['periods_horizontal'][0]))
            print(f"  检测到水平周期: T ≈ {detected_period} 像素")
        else:
            detected_period = known_period
            print(f"  已知周期: T = {detected_period} 像素")
        
        # Step 2: 系统扫描步长
        print(f"\n[2/5] 扫描步长空间 (d=1~{max_step})...")
        scan_results = self.scan_step_size_space(
            texture, max_step=max_step, step_increment=1
        )
        
        # Step 3: 检测共振点
        print("\n[3/5] 检测共振点...")
        contrast_curve = np.mean(scan_results['features']['contrast'], axis=1)
        correlation_curve = np.mean(scan_results['features']['correlation'], axis=1)
        
        if detected_period is not None:
            resonance_contrast = self.detect_resonance_points(
                scan_results['distances'], contrast_curve, detected_period
            )
            resonance_correlation = self.detect_resonance_points(
                scan_results['distances'], correlation_curve, detected_period
            )
        else:
            resonance_contrast = None
            resonance_correlation = None
        
        # Step 4: 计算交互作用度量
        print("\n[4/5] 计算交互作用度量...")
        interaction_metrics = self._compute_interaction_metrics(
            scan_results, detected_period
        )
        
        # Step 5: 生成综合分析报告
        print("\n[5/5] 生成分析报告...")
        analysis_results = {
            'texture': texture,
            'spectral_info': spectral_info,
            'scan_results': scan_results,
            'detected_period': detected_period,
            'resonance_contrast': resonance_contrast,
            'resonance_correlation': resonance_correlation,
            'interaction_metrics': interaction_metrics
        }
        
        return analysis_results
    
    def _compute_interaction_metrics(self, scan_results, period):
        """计算交互作用度量指标"""
        metrics = {}
        
        distances = scan_results['distances']
        contrast = np.mean(scan_results['features']['contrast'], axis=1)
        correlation = np.mean(scan_results['features']['correlation'], axis=1)
        homogeneity = np.mean(scan_results['features']['homogeneity'], axis=1)
        energy = np.mean(scan_results['features']['energy'], axis=1)
        
        # 1. 调制深度
        metrics['contrast_modulation'] = (contrast.max() - contrast.min()) / (contrast.max() + 1e-10)
        metrics['correlation_modulation'] = (correlation.max() - correlation.min()) / (correlation.max() + 1e-10)
        
        # 2. 自相关特征
        autocorr = scan_results['autocorrelation']
        if len(autocorr) > 1:
            # 找到自相关的第一个零点（去相关距离）
            zero_crossings = np.where(np.diff(np.sign(autocorr)))[0]
            if len(zero_crossings) > 0:
                metrics['decorrelation_distance'] = distances[zero_crossings[0]]
            else:
                metrics['decorrelation_distance'] = distances[-1]
        
        # 3. 周期特性（如果有周期信息）
        if period is not None:
            # 在d=T处的特征值
            idx_T = np.argmin(np.abs(distances - period))
            metrics['contrast_at_T'] = contrast[idx_T]
            metrics['correlation_at_T'] = correlation[idx_T]
            
            # 在d=T/2处的特征值
            idx_halfT = np.argmin(np.abs(distances - period/2))
            metrics['contrast_at_halfT'] = contrast[idx_halfT]
            metrics['correlation_at_halfT'] = correlation[idx_halfT]
            
            # 调制比
            metrics['contrast_ratio'] = contrast[idx_halfT] / (contrast[idx_T] + 1e-10)
            metrics['correlation_ratio'] = correlation[idx_T] / (correlation[idx_halfT] + 1e-10)
        
        # 4. 特征稳定性
        metrics['contrast_cv'] = np.std(contrast) / (np.mean(contrast) + 1e-10)
        metrics['correlation_cv'] = np.std(correlation) / (np.mean(correlation) + 1e-10)
        
        return metrics
    
    # ================================================================
    # 辅助方法
    # ================================================================
    def _quantize(self, image):
        """量化图像"""
        mask = image > 0 if image.min() >= 0 else np.ones_like(image, dtype=bool)
        if not mask.any():
            return np.zeros_like(image, dtype=np.uint8)
        
        min_val, max_val = image[mask].min(), image[mask].max()
        if max_val == min_val:
            return np.ones_like(image, dtype=np.uint8)
        
        quantized = np.zeros_like(image, dtype=np.uint8)
        quantized[mask] = np.clip(
            np.round((image[mask] - min_val) / (max_val - min_val) * (self.n_levels - 1)) + 1,
            1, self.n_levels
        ).astype(np.uint8)
        return quantized
```

好的，我们完全抛开代码，只讲**研究思路和逻辑框架**。

你想探究的核心问题是：

> **GLCM的采样步长（d）如何与周期性结构纹理相互作用？**

这是一个典型的"参数敏感性分析"问题。你可以把 GLCM 看作一个**空间滤波器**，步长 `d` 决定了这个滤波器在空间上的采样间隔。当采样间隔与纹理的内在周期发生特定关系时，就会产生共振或相消现象。

---

## 一、核心物理直觉（先理解本质）

在深入流程之前，先建立一个直觉模型：

**想象一个完美的正弦条纹纹理（周期为 T）：**

- **当步长 d = T 时：**
  你每次采样，都正好落在纹理的"同相位"位置。比如你从波峰开始，走一个周期，还是波峰。
  - 此时像素对的值非常相似 → **对比度最低，相关性最高**。
  - GLCM 矩阵的能量会集中在主对角线上。

- **当步长 d = T/2 时：**
  你每次采样，都落在"反相位"位置。从波峰走半个周期，正好是波谷。
  - 此时像素对的值差异最大 → **对比度最高，相关性最低（甚至负相关）**。
  - GLCM 矩阵的能量会集中在反对角线上。

- **当步长 d 与 T 不成简单比例时：**
  采样点之间的相位关系是混乱的，特征值会介于上述两个极端之间。

这就是**步长与周期相互作用的核心机制**。

---

## 二、整体研究流程（逻辑框架）

整个研究可以分为 **5 个递进的阶段**：

### 阶段 0：准备——构建可控的"实验场"

你不能在混乱的真实图像上开始研究，因为变量太多。你需要先创造"干净"的实验条件。

**思路：**
1. **生成具有明确周期 T 的纹理图像**（这是你的自变量之一）。
2. **纹理类型要多样**：正弦波（最纯净）、方波（有谐波）、棋盘格（二维周期）、同心圆（径向周期）。
3. **参数化控制**：周期 T 是你要变化的核心参数（例如 T = 4, 8, 16, 32 像素）。

**目的：** 建立一个"已知答案"的测试集，你知道纹理的周期，然后去看 GLCM 步长如何"发现"这个周期。

---

### 阶段 1：观察——系统扫描步长空间

这是研究的核心实验部分。

**思路：**
1. **固定纹理**（比如一个周期 T=16 的正弦纹理）。
2. **让步长 d 从小到大连续变化**：d = 1, 2, 3, ..., 一直到 2T 或 3T（比如到 48 或 64）。
3. **记录每个步长 d 下的 GLCM 特征**：对比度（Contrast）、相关性（Correlation）、同质性（Homogeneity）、能量（Energy）等。
4. **同时记录自相关函数（Autocorrelation）** 作为参照系。

**目的：** 得到一条"特征值随步长变化"的曲线。这条曲线会呈现出明显的振荡模式，振荡的周期与纹理周期 T 有关。

**此时你应该看到：**
- 对比度曲线在 d = T/2, 3T/2, 5T/2... 处出现**峰值**。
- 相关性曲线在 d = T, 2T, 3T... 处出现**峰值**。
- 两条曲线呈现近似**反相**的关系。

---

### 阶段 2：解释——寻找共振点与特征频率

有了曲线，接下来是分析和解释。

**思路：**
1. **检测极值点**：在特征曲线上，找到对比度的最大值点（反相位共振）和相关性的最大值点（同相位共振）。
2. **计算极值点的步长间隔**：这些间隔应该等于 T 或 T/2。
3. **与纹理的真实周期 T 进行比对**：验证共振点是否精确落在 d = nT 或 d = (2n+1)T/2 上。
4. **观察 GLCM 矩阵形态演变**：在关键步长（d = T/4, T/2, 3T/4, T）处，GLCM 矩阵如何从对角线分布（d小）→ 反对角线分布（d=T/2）→ 回到对角线分布（d=T）。

**目的：** 验证物理直觉，建立"步长-共振-特征响应"的对应关系。

---

### 阶段 3：泛化——改变周期和纹理类型

上述实验只针对一个特定的 T 和一种纹理。现在需要泛化。

**思路：**
1. **改变周期 T**：分别对 T = 8, 16, 32, 64 的纹理重复阶段 1 的实验。
2. **归一化对比**：将横坐标从"绝对步长 d"改为"归一化步长 d/T"。你会发现，不同 T 的曲线在归一化后**几乎重合**！这证明了尺度不变性：决定特征的是 d/T 这个比值，而不是 d 的绝对值。
3. **改变纹理类型**：对方波、棋盘格、同心圆纹理重复实验。
   - 方波由于包含高频谐波，共振峰会变得更尖锐，并且在 T/3, T/4 等分数位置可能出现次峰。
   - 棋盘格在两个方向都有周期，角度维度的影响会更显著。
4. **改变方向**：不仅看水平方向（θ=0°），还要看垂直（θ=90°）和对角（θ=45°）方向。如果纹理是水平的，那么垂直方向的 GLCM 对步长的敏感性会很弱。

**目的：** 验证发现的普适性，并理解边界条件（纹理类型、方向性）的影响。

---

### 阶段 4：量化——定义交互作用度量指标

光看图不够，需要把这种交互作用**量化**成几个关键指标。

**思路：**
1. **调制深度（Modulation Depth）**：
   - 定义：`(特征最大值 - 特征最小值) / 特征最大值`
   - 含义：纹理的周期结构对 GLCM 特征的影响有多大。调制深度越大，说明纹理的周期性越强。

2. **共振比（Resonance Ratio）**：
   - 定义：`对比度在 d=T/2 的值 / 对比度在 d=T 的值`
   - 含义：这个比值越大，说明周期纹理被 GLCM 捕捉得越清晰。

3. **去相关距离（Decorrelation Distance）**：
   - 定义：自相关函数第一次下降到某个阈值（如 1/e）时的滞后距离。
   - 含义：反映了纹理中像素值保持相似的最大空间范围。这个距离应该与 T 正相关。

4. **特征变异系数（Coefficient of Variation of Features）**：
   - 计算所有步长下特征的均值和标准差，CV = std/mean。
   - 含义：CV 越大，说明选择不同的步长对结果影响越大，即纹理对步长越敏感。

**目的：** 建立一套定量语言，用于描述和比较不同纹理与步长的交互强度。

---

## 三、总结：研究的"故事线"

当你要写报告或做演示时，可以按照这个逻辑展开：

1. **动机**：GLCM 是经典工具，但步长选择往往是盲目的（通常是 [1,2,4,8]）。我们需要理解步长到底在"看"什么。

2. **方法**：我们设计了一个可控实验，用已知周期的合成纹理，系统扫描步长，观察 GLCM 特征的响应。

3. **核心发现**：
   - GLCM 特征随步长**周期性振荡**，振荡周期等于纹理周期 T。
   - 这种振荡的物理原因是：步长与纹理周期的相位匹配/失配。
   - 对比度和相关性是两个互补的"探针"，分别在反相位和同相位共振。

4. **实际指导意义**：
   - **不要盲目用 [1,2,4,8]**：如果纹理有大约 16 像素的周期，你应该包含 d=8 和 d=16 来捕获共振。
   - **多步长组合的必要性**：不同步长捕获不同尺度的信息，组合它们才能完整描述纹理。
   - **通过特征曲线反推周期**：如果在某个未知纹理上，你看到对比度在 d=10 处有个峰值，那么可以推测该纹理的水平方向存在大约 T=20 像素的周期结构。

这样，你就完成了从"用工具"到"理解工具"的跨越。
