现在发现优化不会有很多个 Iter，基本就是 initial_params=(-1.0, 1.0, -1.0), 写了啥就试这一个，怎么调参才能让模型多试几个 Iter


你现在“只试一个 Iter”的原因通常不是 `max_iter` 太小，而是这里：

```python
if candidate_loss < current_loss:
    params = candidate_params
    updated = True
    break

...
if not updated:
    print("Stop: loss no longer decreases.")
    break
```

也就是说：**第 0 轮算完梯度后，沿梯度方向怎么走都没有让 RIU loss 下降，所以直接停了。**

RIU 比 SSD 难优化很多，建议这样调：

```python
registered_t1_coronal_riu, best_params_riu, registration_history_riu = steepest_descent_registration(
    fixed_image=fixed_image,
    moving_image=moving_image,
    mask=registration_mask,
    initial_params=(-1.0, 1.0, -1.0),
    metric="RIU",
    max_iter=100,
    learning_rate=0.01,
    gradient_eps=(0.2, 0.5, 0.5)
)
```

如果还停，再更小：

```python
learning_rate=0.001
gradient_eps=(0.1, 0.2, 0.2)
```

重点是：

- `learning_rate=5.0` 对 RIU 太大了。
- 你的梯度范数之前有 `8.699`，那么一步大概会走：
  ```python
  5.0 * 8.699 ≈ 43.5
  ```
  这对角度和平移来说都太猛，RIU 很容易直接变差。
- RIU 对 `moving_image` 里的 0 或接近 0 很敏感，loss 地形不平滑，所以要小步走。

另外你现在主循环只每 10 轮打印一次：

```python
if iteration % 10 == 0:
```

如果你想看到每一轮，把它改成：

```python
if iteration % 1 == 0:
```

或者直接去掉判断。

更稳的策略是：先用 SSD 找到一个不错的初始参数，再用 RIU 微调：

```python
# 先 SSD
registered_t1_coronal, best_params, _ = steepest_descent_registration(
    fixed_image=fixed_image,
    moving_image=moving_image,
    mask=registration_mask,
    initial_params=(0.0, 0.0, 0.0),
    metric="SSD",
    max_iter=100,
    learning_rate=200.0,
    gradient_eps=(0.5, 1.0, 1.0)
)

# 再 RIU
registered_t1_coronal_riu, best_params_riu, registration_history_riu = steepest_descent_registration(
    fixed_image=fixed_image,
    moving_image=moving_image,
    mask=registration_mask,
    initial_params=best_params,
    metric="RIU",
    max_iter=100,
    learning_rate=0.001,
    gradient_eps=(0.1, 0.2, 0.2)
)
```

总结一下优先级：先把 `learning_rate` 降到 `0.01` 或 `0.001`，再把 `gradient_eps` 降小；如果还不稳定，就用 SSD 的结果作为 RIU 的 `initial_params`。

我现在更新了 debug.ipynb 文件，加入了 2.4 部分。这部分是用任何方法来提高配准的效果。我认为可以优化的几个点有：

1. 初始点的选取，对于基于 RIU 指标的  SGD 方法，初始点的选取会对结果有较大的影响。这说明对于 RIU 的空间有很多局部最小值，正常优化很容易导致结果落到一个局部最小值。为了避免以上情况，可以采用多分辨率配准。先将图像缩小到低分辨率，让模型先确定一个大致的方向，将该优化的结果作为正式优化过程的初始点。

2. 从损失曲线来看，对于没有很多局部最小值的情况，刚开始的学习率可以大一点，当接近局部最小值后再减小学习率，进行微调。

3. 同模态和跨模态主要参考的参数是不同的，同模态主要用 SSD，而跨模态主要参考 RIU，因此可以添加参数来确定同模态还是跨模态，据此来确定选取的优化指标。
